# Quickstart: UI Fixes and Plan Adjustments

This branch (`002-ui-plan-fixes`) introduces UI component updates, translations integration, and layout standardizations to the Academic Advisor application. 

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Navigate to `http://localhost:5173`. 
4. Toggle the language in the top right to verify Arabic translations across all views.
5. Search for a student profile, view horizontal scroll components, generate a new plan with numeric years, and try navigating their profile tabs.
