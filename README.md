# Damietta University — Academic Advisor

A high-end, intelligent graduation planning platform for students of the **Faculty of Computing and Artificial Intelligence** at Damietta University. It features a modern, professional interface that streamlines academic advising through automated roadmap generation and interactive visual tools.

## Key Features

### 🎓 Student Portal (Premium Interface)
- **Visual Prerequisite Graph** — An interactive dependency map that helps students understand their academic path and see exactly how courses unlock future requirements.
- **Academic Dashboard** — Real-time tracking of GPA (with classification), passed hours, and overall graduation progress through elegant visual indicators.
- **Plan Management** — View approved semester plans generated by advisors. Access a unified history of both draft and approved plans in one place.
- **Support Ticket System** — Submit academic queries or transcript requests with file attachments. Track ticket status and receive direct advisor feedback.
- **Course Library Analysis** — Categorized view of all remaining requirements (University, Basic Science, College, Major) with granular progress bars for mandatory/elective credits.

### 🛡️ Admin Management System
- **Unified Student Profiles** — Detailed view of each student including academic history, real-time GPA calculations, and plan management.
- **Drag-and-Drop Plan Editor** — Interactively build semester roadmaps by dragging courses from the library directly into the student's plan.
- **Bulk Plan Generation** — One-click automated drafting of semester plans for all registered students, allowing advisors to review and refine before approval.
- **Ticket Resolution Center** — Dedicated hub for managing student inquiries, reviewing transcript uploads, and providing official feedback.
- **Course Database Control** — Full CRUD management for the 119-course catalog, including prerequisite mapping and availability toggles.

### ⚙️ Intelligent Course Engine
- **Constraint-Based Algorithm** — Generates recommendations that strictly adhere to prerequisites, term availability, and GPA-based credit limits (18 Cr / 12 Cr caps).
- **Major-Specific Logic** — Custom rules and requirements for CS, IT, and IS majors, including cross-listed course handling.
- **Duplicate Prevention** — Ensures only one valid plan exists per student per semester (Year + Term).

## Getting Started

```bash
# Clone
git clone https://github.com/SheedoM/Damietta-Academic-Advisor.git
cd Damietta-Academic-Advisor

# Install
npm install

# Dev server
npm run dev

# Production build
npm run build
```

## Upcoming Development

### 💾 Consistent Cloud Storage
The current system operates on local persistence. The next phase involves:
- **Scalable Backend** — Moving to a PostgreSQL/Firebase architecture to support real-time data sync across all advisor and student devices.
- **Multi-User Sync** — Real-time updates when an advisor approves a plan, immediately notifying the student.
- **Student Authentication** — Moving from ID-based lookup to secure JWT-based authentication.

### 🤖 AI-Powered Academic Bot
Integration of a Large Language Model (LLM) to act as a 24/7 Academic Assistant:
- **Plan Explanation** — Bot explains the logic behind specific course sequences based on bylaws.
- **Bylaw Querying** — Natural language interface for students to ask about graduation requirements.
- **What-If Analysis** — Students can ask the bot to simulate different major choices or elective paths.
